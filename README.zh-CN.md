## 这是什么？

**绀海之约**是一款面向长篇小说创作的 Android 应用。

它是一款借鉴“酒馆”式上下文管理体验的轻量级 AI 写小说工具，制作初衷很简单：方便上班摸鱼时，也能随手写几段属于自己的故事。

它不是把写作简单包装成聊天，也不会让 AI 悄悄改动正文。你的作品、章节、设定、总结、候选与创作记录都以本地数据为核心保存；AI 生成的内容会先成为候选，只有经过你的查看、修改和确认，才会真正写入故事。

> 正文属于作者。AI 只负责带来新的可能。

## 为什么选择绀海之约？

| 你关心的事情 | 绀海之约的做法 |
| --- | --- |
| 正文会不会被 AI 直接覆盖？ | 不会。模型输出先进入候选，确认后才追加到正文。 |
| 长篇故事的设定怎么延续？ | 通过故事记忆、预设、世界书与分层总结持续维护。 |
| 多个生成结果怎么比较？ | 候选可切换、编辑、重新生成、单独删除或整组清理。 |
| 模型思考会不会混进小说？ | 不会。思考过程与最终内容分开显示和保存。 |
| 能否知道实际发送了什么？ | 每次生成前都能检查故事记忆、消息顺序与完整请求。 |
| 写作数据放在哪里？ | 作品数据优先保存在 Android 设备本地。 |
| 换手机或误操作怎么办？ | 支持带密码的完整加密备份、恢复与恢复前回滚。 |

## 核心能力

### 📚 一部作品，一本独立的书

- 最外层书架集中管理多部作品。
- 每本书拥有独立章节、模型、设定、总结、历史与助手会话。
- 可从系统相册选择封面，并通过拖动、双指缩放裁剪为固定 2:3 比例。

### ✍️ 专注而可靠的正文编辑

- 连续正文自动保存在本机。
- 章节信息默认折叠，把更多屏幕留给故事本身。
- 支持章节创建、排序、回收与恢复。
- 手机键盘弹出时仍尽量保留可见、可编辑的正文区域。

### ✨ AI 候选，而不是自动代写

- 输入这一次的创作方向，在发送前检查模型将收到的内容。
- 流式接收正文或总结候选。
- 在多个候选之间切换、修改、重新生成或删除。
- 只有点击采用后，内容才会进入正式正文。
- 中途停止或网络断开时，已经收到的部分仍可保留和处理。

### 🧠 能长期陪伴故事的记忆

- 自由决定哪些章节和总结参与下一次创作。
- 使用预设与世界书维护写作约定、人物信息和世界规则。
- 总结会追踪自己的来源；原文变化后，应用会提醒重新整理。
- 全局灵感素材只有复制到当前作品并主动启用后才会参与生成。

### 💬 灵感对谈

- 每部作品拥有一段独立、可持续的灵感对话。
- 助手可以讨论人物动机、剧情冲突与后续方向。
- 对话不会擅自改写正文，也不会把模型思考带入下一轮内容。

### 🔎 看得见的创作过程

- 发送前查看故事记忆、最终消息与脱敏后的完整请求。
- 在“创作足迹”中回看模型原稿、作者修改稿、候选状态和实际用量。
- 上下文用量以圆环直观呈现，点击后再显示具体 Token 数值。
- 已写入正文的内容可以在安全条件下撤回，同时保留历史痕迹。

## 创作流程

> **书架** → **编辑正文** → **写下本次方向** → **发送前检查** → **比较候选** → **修改并采用** → **留下创作足迹**

如果结果不合适，可以重新生成、删除候选或直接回到输入处继续调整；未采用的内容不会悄悄进入正文。

## 使用方式

### 1. 开始一个故事

1. 打开应用，在书架点击“开始一个故事”。
2. 输入故事名称，第一章会随之创建。
3. 点击封面上的相片按钮，可从相册选择并裁剪封面。
4. 即使没有配置任何 AI 模型，也可以直接进行本地写作。

### 2. 配置 AI 模型

1. 进入作品后打开“设置”。
2. 选择模型供应商。
3. 填写 Base URL 与 API Key，并完成连接验证。
4. 为正文、总结和灵感对谈选择模型。
5. 根据需要调整温度、最大输出、流式生成与思考强度。

### 3. 生成并选择正文

1. 在正文下方写下这一次的创作方向。
2. 点击“检查并生成”。
3. 在发送前检查页确认故事记忆、发送内容和模型参数。
4. 浏览并修改候选，选择满意的版本。
5. 点击“接受并追加”，候选才会写入当前章节末尾。

### 4. 维护故事记忆

进入“记忆”页面，可以：

- 勾选下一次创作需要参考的章节与总结。
- 整理新的故事总结。
- 管理本作预设和世界书。
- 把常用灵感素材收藏到全局素材库。

### 5. 定期备份

在设置中创建带密码的 <code>.ainovelbackup</code> 完整备份。备份可包含作品、封面、章节、模型配置、候选、历史以及加密保护的连接信息。

请妥善保存备份文件和密码：密码不会上传，也无法由应用代为找回。

## 数据与隐私

“本地优先”不等于“完全离线”。本地写作不需要联网；当你主动使用在线模型生成时，经过发送前检查的内容会直接发往你选择的模型供应商。

| 数据 | 处理方式 |
| --- | --- |
| 小说、章节、总结、候选与历史 | 保存在设备本地数据库与应用私有目录 |
| API Key | 使用 Android Keystore 支持的加密能力保存 |
| 请求历史 | 保存脱敏内容，不记录明文密钥与鉴权头 |
| 未采用候选与模型思考 | 不进入正式正文或后续故事记忆 |
| 全局素材 | 不会自行发送，必须复制到作品并主动启用 |
| 完整备份 | 使用用户密码进行认证加密 |

在使用任何在线模型前，请同时阅读对应供应商的隐私政策与数据保留规则。

## 本地构建

构建环境：

- JDK 17 或更高版本
- Android SDK 36
- 可用的 Android 构建工具链

Windows：

<pre><code>./gradlew.bat :app:assembleDebug</code></pre>

macOS / Linux：

<pre><code>./gradlew :app:assembleDebug</code></pre>

<pre><code>app/build/outputs/apk/debug/app-debug.apk</code></pre>
